# ربات تلگرامی پیش‌بینی سیکل قاعدگی

یه Cloudflare Worker که بر اساس طول سیکل، تاریخ شروع دوره‌ی بعدی رو پیش‌بینی می‌کنه و قبل از رسیدنش (۷، ۳، ۲، ۱ روز مونده و روز خودش) تو تلگرام یادآوری خودکار می‌فرسته. از حالت دونفره هم پشتیبانی می‌کنه: یه نفر تاریخ رو ثبت و مدیریت می‌کنه (owner)، نفر دوم فقط با یه لینک دعوت بهش وصل می‌شه و همون پیش‌بینی‌ها و هشدارها رو می‌گیره، بدون اینکه خودش چیزی ثبت کنه.

## چجوری کار می‌کنه

- **Owner (صاحب پروفایل):** کسی که واقعاً داره ردیابی می‌کنه: یه بار `/setstart` (یا `/today`) می‌زنه، و ربات خودش از روی یه طول سیکل ثابت همیشه جلو می‌ره. لازم نیست هر ماه دستی آپدیتش کنی، مگه تاریخ واقعی فرق کنه.
- **Viewer (وصل‌شده):** هرکسی که owner دعوتش کنه (با `/invite`): بدون اینکه خودش چیزی وارد کنه، داده‌ی owner رو دنبال می‌کنه و دقیقاً همون هشدارها رو می‌گیره.
- یه کار زمان‌بندی‌شده (Cron Trigger) هر روز چک می‌کنه چند روز تا تاریخ پیش‌بینی‌شده مونده و به همه‌ی درگیرها (owner و تمام viewer هاش) رو ۷، ۳، ۲، ۱ روز مونده و روز خودش پیام می‌فرسته. هر پیام هشدار یه دکمه‌ی **«How's today?»** هم داره برای چک سریع وضعیت.
- `/history` طول واقعی سیکل‌های قبلی رو نشون می‌ده (از روی تاریخ‌هایی که واقعاً ثبت کردی)، نه فقط عددی که با `/setcycle` گذاشتی.
- همه‌ی داده‌ها تو یه دیتابیس Cloudflare D1 ذخیره می‌شه.

## راه‌اندازی — فقط با داشبورد Cloudflare (بدون نیاز به ترمینال)

### ۱. ساخت ربات تلگرام
- تلگرام رو باز کن، دنبال **BotFather@** بگرد، بزن `/newbot` و مراحل رو دنبال کن.
- BotFather یه **توکن** (چیزی شبیه `123456:ABC-...`) و یه **یوزرنیم** (مثلاً `mybot`، بدون `@`) بهت می‌ده — هر دو رو ذخیره کن.
- یه پیام به بات جدیدت بفرست (تا تلگرام یه چت باهات داشته باشه).
- برای پیدا کردن **chat ID** خودت، این آدرس رو تو مرورگر باز کن (جای `<TOKEN>` توکنتو بذار):
  `https://api.telegram.org/bot<TOKEN>/getUpdates`
  دنبال `"chat":{"id": ...}` تو جواب بگرد — همون عدد `CHAT_ID` توئه.

### ۲. ساخت Worker
- برو تو [داشبورد Cloudflare](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Create Worker**.
- یه اسم بذار (مثلا `period-tracker-bot`) → **Deploy** بزن (این یه کد پیش‌فرض دیپلوی می‌کنه، مشکلی نیست، قدم بعد عوضش می‌کنیم).

### ۳. کد رو جایگزین کن
- برو تو Worker جدیدت → دنبال دکمه‌ای مثل **Edit code** بگرد (بعضی وقتا تو تب Overview هست).
- هر چی تو ادیتور هست پاک کن، کل محتوای فایل `Worker.js` از این ریپازیتوری رو کپی-پیست کن.
- بزن **Save and Deploy**.

### ۴. ساخت دیتابیس D1
- تو منوی سمت چپ داشبورد Cloudflare، دنبال **Storage & Databases** → **D1 SQL Database** → **Create** بگرد.
- یه اسم بذار (مثلا `period-db`) → **Create**.
- دیتابیس جدید رو باز کن → برو تو تب **Console** → کل محتوای فایل `Schema.sql` از این ریپازیتوری رو پیست کن و اجرا کن (جدول‌های `profiles`، `links`، و `cycle_history` رو می‌سازه).

### ۵. وصل کردن دیتابیس به Worker
- برگرد تو Worker‌ت → تب **Bindings** → **Add** → گزینه **D1 database** رو انتخاب کن.
- دیتابیسی که ساختی رو انتخاب کن.
- **Variable name** رو دقیقاً بذار `DB` (کد همین اسم رو انتظار داره).
- ذخیره کن.

### ۶. اضافه کردن Secrets و متغیرها
- تو Worker‌ت → **Settings** → **Variables and secrets** → **Add**.
- دو تا متغیر از نوع **Secret** اضافه کن:
  - `BOT_TOKEN` — توکنی که از BotFather گرفتی
  - `CHAT_ID` — chat ID‌ای که تو قدم ۱ پیدا کردی
- یه متغیر ساده از نوع **Text** هم اضافه کن:
  - `BOT_USERNAME` — یوزرنیم بات‌ت (بدون `@`) — برای ساختن لینک‌های دعوت قابل‌کلیک استفاده می‌شه

### ۷. اضافه کردن Cron Trigger روزانه
- تو Worker‌ت → **Settings** → **Trigger events** (Cron Triggers) → **Add**.
- برو تو تب **Cron expression** و این رو بنویس:
  ```
  0 21 * * *
  ```
  (یه بار در روز اجرا می‌شه؛ ساعت رو هر وقت که می‌خوای هشدارها بیان تنظیم کن)
- بزن **Add**.

### ۸. وصل کردن تلگرام به Worker (Webhook)
- این آدرس رو تو مرورگر باز کن (جای `<TOKEN>` توکن بات و جای `<your-worker>` ساب‌دامین واقعی Worker‌ت که تو صفحه‌ی Overview نشون داده می‌شه رو بذار):
  ```
  https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<your-worker>.workers.dev
  ```
- باید `{"ok":true,"description":"Webhook was set"}` ببینی.

### ۹. شروع استفاده
یه چت با بات‌ت باز کن و بزن `/start`. ازت می‌خواد انتخاب کنی:
- **Track for myself** — بعدش `/setstart YYYY-MM-DD` (یا `/today`) بزن تا شروع کنی.
- **I have an invite code** — بعدش `/link CODE` رو با کدی که شریکت داده بزن.

بعد از راه‌اندازی، owner می‌تونه `/invite` بزنه و یه کد + یه لینک قابل‌کلیک بگیره — با فرستادن اون لینک، شریکش با یه تپ وصل می‌شه، بدون نیاز به تایپ چیزی.

## راه‌اندازی — با Wrangler CLI (روش جایگزین، اگه ترمینال داری)

```bash
wrangler d1 create period-db
# database_id ای که چاپ می‌کنه رو تو Wrangler.toml بذار

wrangler d1 execute period-db --file=./Schema.sql --remote

wrangler secret put BOT_TOKEN
wrangler secret put CHAT_ID

wrangler deploy

curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<your-worker>.workers.dev"
```

`BOT_USERNAME` رو به‌عنوان یه متغیر ساده تو بخش `[vars]` فایل `Wrangler.toml` بذار، یا همون‌طور که بالا گفته شد از داشبورد اضافه‌ش کن.

## دستورات ربات

| دستور | توضیح |
|---|---|
| `/start` | انتخاب نوع استفاده (ردیابی برای خودت، یا دنبال کردن یکی دیگه با کد دعوت) |
| `/help` | نمایش دوباره‌ی لیست دستورات |
| `/next` | تاریخ پیش‌بینی‌شده‌ی بعدی، یا چند روز مونده اگه الان تو دوره‌ای |
| `/today` | ثبت امروز به‌عنوان تاریخ شروع دوره (میان‌بر برای `/setstart` با تاریخ امروز) |
| `/setstart YYYY-MM-DD` | ثبت آخرین تاریخ شروع دوره‌ی خودت |
| `/setcycle N` | تنظیم طول سیکل به روز (پیش‌فرض ۲۸) |
| `/setlength N` | تنظیم طول دوره به روز (پیش‌فرض ۵) |
| `/history` | نمایش سیکل‌های اخیر و طول واقعی هرکدوم |
| `/invite` | گرفتن کد و لینکی که می‌تونی با شریکت به اشتراک بذاری |
| `/link CODE` | دنبال کردن دوره‌ی یکی دیگه با کد دعوتش |
| `/unlink` | قطع دنبال کردن دوره‌ی اون شخص |
| `/removeprofile` | پاک کردن داده‌ی ردیابی خودت (اگه فقط می‌خوای دنبال یکی دیگه باشی) |

هر پیام هشدار هم یه دکمه‌ی **«How's today?»** داره برای چک سریع وضعیت با یه تپ.

هر وقت بخوای می‌تونی `/start` یا `/help` رو بزنی تا دوباره این منو یا لیست دستورات رو ببینی.

## فایل‌ها

- `Worker.js` — کد Worker
- `Wrangler.toml` — تنظیمات Worker (`database_id` خودتو بذار توش)
- `Schema.sql` — ساختار جدول‌های D1
